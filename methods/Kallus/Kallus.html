Kallus

The parametric Kallus & Zhou regret-minimiser — a softmax policy class. Single file kallus.py (fit_kallus, predict_kallus). Flat: no Capped/Uncapped, no grid discretisation.

One sentence. Kallus learns softmax policy parameters \(\theta\) that minimise the worst-case regret of the policy relative to the all-control baseline \(\pi_0\), over the marginal-sensitivity box (optionally ∩ Wasserstein) — the parametric counterpart of the free-π Regret-O / Hajek-OW LPs.
Derivation note (no old reference). The repository only contained a parametric value maximiser (parametric R-OW/R-O). This method is a NEW derivation: same softmax machinery + outer subgradient loop + inner Gurobi LP, but the inner is the worst-case regret and the outer descends it. There is no legacy solver to bit-check against; it is verified by construction and sanity.

1 · The policy class & inputs

\[ \pi_\theta(k\mid x)=\operatorname{softmax}_k\big(\theta_0^\top\varphi(x),\dots,\theta_{K-1}^\top\varphi(x)\big),\qquad \theta\in\mathbb R^{K\times p}, \]

with feature map \(\varphi\) (basis: affine / poly / rbf). Inputs: covariates \(x_i\), arm \(T_i\), outcome \(Y_i\), and the nominal inverse weights \(\hat w_i\) (estimated upstream — never the true propensities); sensitivity \(\Gamma\); and, for the Wasserstein variant, radii \(\varepsilon_k\). No discretisation — the softmax is a smooth function of the raw \(x\), so there is no discretize/mesh and no Shapley/KNN extension (deploy with predict_kallus directly).

2 · The in-sample problem (min worst-case SELF-NORMALISED regret)

Kallus & Zhou use the Hájek (self-normalised) regret: per arm \(t\) the value is normalised by the weights' own mass, so the denominator floats with \(w\). With all-control baseline \(\pi_0\),

\[ \boxed{\;\min_{\theta}\ \sum_t\ \sup_{w\in\mathcal U(\Gamma[,\varepsilon])}\ \frac{\sum_{i:T_i=t}\big(\mathbf 1[t=0]-\pi_\theta(t\mid x_i)\big)Y_iw_i}{\sum_{i:T_i=t}w_i}\;} \]

where \(\mathcal U\) is the marginal-sensitivity box \(a_i\le w_i\le b_i\), built on the raw inverse weights \(\tilde W_i=1/\hat P(T_i\mid x_i)\ge1\) (so \(a_i\ge1>0\) and the denominator stays positive). For wasserstein=False (the studies' setting) this is exactly Regret-O's box; for wasserstein=True the per-arm Wasserstein balls are added (= Hajek-OW's set, where the transport's mass-balance pins \(\sum_{T_i=t}w_i=n\), so that variant is self-normalised with denominator \(n\)). No explicit \(\sum w=n\) calibration is imposed in the box case — the self-normalisation IS the calibration (Kallus & Zhou Eq. 4, 10).

3 · How it is solved

Inner (fixed \(\theta\)): a Gurobi LP returns the worst-case \(w^\star\) and the regret — a MAX over \(\mathcal U\) of \(\frac1n\sum_i(\mathbf 1[T_i=0]-\pi_\theta(T_i|x_i))Y_iw_i\). Outer: subgradient descent on the regret envelope. Since the \(\pi_0\) term is \(\theta\)-free, \(\partial R/\partial\theta=-\partial V(\pi_\theta,w^\star)/\partial\theta\), so descending regret means ascending the policy value at \(w^\star\):

\[ \theta\ \leftarrow\ \theta+\frac{\eta_0}{(k+1)^{\kappa}}\,\Big[\big(\tfrac{Y\odot w^\star}{n}\big)\odot\pi_\theta(T\!\mid\!X)\,(\mathrm{onehot}-\pi_\theta)\Big]^{\!\top}\varphi(X), \]

over n_restarts random inits × n_iters steps. Per restart we return the Polyak iterate-average \(\bar\theta=\tfrac1{n_{\text{iters}}}\sum_k\theta_k\); across restarts we keep the \(\bar\theta\) with the smallest worst-case regret. The per-unit \(\pi_\theta(T_i\!\mid\!X_i)\) factor makes this the exact policy gradient \(\nabla\pi\) (Kallus & Zhou, Algorithm 1), not the score-function \(\nabla\log\pi\).

Outcome convention (maximize). Default True treats \(Y\) as a reward — regret \(=V(\pi_0)-V(\pi)\), the studies' convention; maximize=False treats \(Y\) as a loss (Kallus & Zhou's exact convention, regret \(=V(\pi)-V(\pi_0)\)), implemented by negating \(Y\).

4 · How it is solved — inner LP + outer subgradient (no single LP)

Unlike the free-π R-O / R-OW methods, Kallus is parametric (softmax in \(\theta\)), so the objective is nonconvex in \(\theta\) and the problem is not a single LP. It alternates an exact inner LP (fixed \(\theta\)) with an outer subgradient step on \(\theta\). The steps below trace one full pass; we write \(w\) for the adversary's weight vector.

Step 1 — inner problem (fixed \(\theta\), per-arm self-normalised sup). Form the policy \(\pi_\theta\) and its observed-arm probabilities \(\pi_\theta(T_i\mid x_i)\). The worst-case regret is the per-arm Hájek ratio
\[ \sum_t\ \sup_{w\in\mathcal U}\ \frac{\sum_{i:T_i=t}\big(\mathbf 1[t=0]-\pi_\theta(t\mid x_i)\big)Y_iw_i}{\sum_{i:T_i=t}w_i}, \]
a linear-fractional program per arm. The box case is solved fast by a Dinkelbach root-find (no LP); the Wasserstein case by a transport LP per level. It returns the per-arm normalised maximiser \(w^\star\) (\(\sum_{T_i=t}w^\star_i=1\)) and the regret value.
Step 2 — envelope subgradient. Because the \(\pi_0\) term \(\mathbf 1[T_i=0]\) is \(\theta\)-free, Danskin's envelope theorem gives \(\partial R/\partial\theta=-\,\partial V(\pi_\theta,w^\star)/\partial\theta\): descending the regret means ascending the policy value at the frozen \(w^\star\). Using the exact softmax gradient \(\nabla_\theta\pi_\theta(T_i\!\mid\!X_i)=\pi_\theta(T_i\!\mid\!X_i)\,(\mathrm{onehot}_i-\pi_\theta)\,\varphi(X_i)\) — note the per-unit \(\pi_\theta(T_i\!\mid\!X_i)\) factor; this is \(\nabla\pi\) (Kallus & Zhou, Algorithm 1), not the score-function \(\nabla\log\pi\) — the ascent direction is
\[ \mathrm{grad}\;=\;\Big[\big(\tfrac{Y\odot w^\star}{n}\big)\odot\pi_\theta(T\!\mid\!X)\,(\mathrm{onehot}-\pi_\theta)\Big]^{\!\top}\varphi(X). \]
Step 3 — outer update. Take a single decaying subgradient ascent step,
\[ \theta\ \leftarrow\ \theta+\frac{\eta_0}{(k+1)^{\kappa}}\,\mathrm{grad}, \]
repeated for n_iters steps, over n_restarts random initialisations.
Step 4 — average & select. Per restart, return the Polyak iterate-average \(\bar\theta=\tfrac1{n_{\text{iters}}}\sum_k\theta_k\) (Algorithm 1, line 7); across the n_restarts restarts keep the \(\bar\theta\) with the smallest worst-case regret — a guard against the nonconvex landscape, since different random initialisations can converge to different optima.
Step 5 — solve. Each inner problem is a Gurobi LP; the outer loop is plain subgradient ascent in numpy. No dual certificate is stored — the global problem is not an LP, so there is no single dual to certify (contrast R-O / R-OW, which save \((\beta,\mu,\nu)\)).

How it is used. The fit returns \(\theta\); deploy to new covariates with predict_kallus(\theta, X) directly — the softmax is smooth, so there is no Shapley/KNN extension.

5 · Caveats & why it is flat

  • Regret can be \(>0\). For the free-π LP the all-control \(\pi_0\) is feasible, so regret \(\le 0\) ("do-no-harm"). The softmax class cannot represent \(\pi_0\) exactly (it needs \(\theta\to\infty\)), so the parametric worst-case regret may be slightly positive — the cost of the smooth, restricted policy class.
  • No capacity (flat folder). A hard per-arm capacity is a population constraint the free-π LP can impose; a smooth parametric policy cannot, so Kallus has a single, uncapped form.
  • No discretisation. Parametric ⇒ the policy generalises across continuous \(x\) directly.

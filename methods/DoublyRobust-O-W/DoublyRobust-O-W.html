R-OW-DoublyRobust

Robust AIPW (doubly-robust) value maximiser over the OW (odds / MSM box ∩ per-arm Wasserstein balls) uncertainty set. Files: Capped/r_ow_doublyrobust_capped.py, Uncapped/r_ow_doublyrobust_uncapped.py.

One sentence. R-OW-DoublyRobust anchors the policy value on an outcome model \(\hat\mu\) and makes only the leftover IPW correction robust over R-OW's set — the marginal-sensitivity box and the per-arm Wasserstein covariate-balance balls — combining R-OW's balance robustness with doubly-robust efficiency.
Design note (new derivation). This is the missing combination: the doubly-robust objective of DoublyRobust paired with R-OW's box ∩ Wasserstein uncertainty set. It is R-OW's dual LP with the outcome residual in place of \(Y\), plus the direct outcome term. Correctness is anchored by a reduction (μ̂ ≡ 0 ⇒ R-OW), not an old reference.

2 · The in-sample problem (robust AIPW value, OW set)

Write the factual residual \(r_i = Y_i - \hat\mu_{T_i}(X_i)\). R-OW-DoublyRobust maximises the outcome-model value plus the worst-case residual IPW correction over R-OW's set:

\[ \boxed{\;\max_{\pi\in\Pi}\ \underbrace{\frac1n\sum_{i}\sum_{k}\pi_k(x_i)\,\hat\mu_k(x_i)}_{\text{direct (outcome model)}}\;+\;\underbrace{\min_{w\in\mathcal U_{\mathrm{OW}}(\Gamma,\varepsilon)}\ \frac1n\sum_{i}\pi_{T_i}(x_i)\,w_i\,r_i}_{\text{worst-case residual correction}}\;} \]

with \(\Pi\) the valid-policy set (simplex per cell, tie on each cell, and \(\frac1n\sum_i\pi_k\le\mathrm{cap}_k\) for the capped version), and the OW set

\[ \mathcal U_{\mathrm{OW}}(\Gamma,\varepsilon)=\Big\{\,w:\ \underbrace{a_i\le w_i\le b_i\ \ \forall i}_{\text{(O) odds / MSM box}}\ \ \text{and}\ \ \underbrace{\mathcal W_{D}\!\big(\hat{\mathbb P}_k,\ \mathbb P^{w}_k\big)\le\varepsilon_k\ \ \forall k}_{\text{(W) Wasserstein covariate balance}}\,\Big\}, \]

i.e. exactly R-OW's box ∩ per-arm Wasserstein-ball set, here acting on the residual \(r\) instead of \(Y\). \(a_i=1+\Gamma^{-1}(\hat w_i-1),\ b_i=1+\Gamma(\hat w_i-1)\).

3 · What is actually solved (dual LP)

Dualising the inner \(\min_w\) gives R-OW's box + Wasserstein dual with \(Y\to r\), plus the (dual-free) direct term added to the objective. Variables \(\pi_k(x_i)\); \(\beta_k\ge 0\) (W-radius); \(\gamma_{k,i},\theta_{k,j}\) (transport, free); \(\mu_i,\nu_i\ge 0\) (box).

\[ \max_{\pi,\beta\ge0,\gamma,\theta,\mu\ge0,\nu\ge0}\ \ \frac1n\sum_i\sum_k\pi_k(x_i)\hat\mu_k(x_i)\;+\;\sum_k\Big(-\beta_k\varepsilon_k+\tfrac1n\sum_i\gamma_{k,i}\Big)\;+\;\sum_i\big(a_i\mu_i-b_i\nu_i\big) \]
\[ \text{s.t.}\quad \tfrac1n\,\pi_k(x_i)\,r_i+\tfrac1n\,\theta_{k,i}-\mu_i+\nu_i\ge0\ \ \forall k,\ i\in I_k;\qquad \beta_k D_{ij}-\gamma_{k,i}-\theta_{k,j}\ge0\ \ \forall k,\ i,\ j\in I_k; \]
\[ \textstyle\sum_k\pi_k(x_i)=1,\ \pi\ \text{tied per cell};\qquad \underbrace{\tfrac1n\textstyle\sum_i\pi_k(x_i)\le\mathrm{cap}_k}_{\textbf{capped only}};\qquad \beta_k,\mu_i,\nu_i\ge0, \]

where \(I_k=\{i:T_i=k\}\) are arm \(k\)'s factual rows. Only the residual-correction (the dual-feasibility row) changes relative to R-OW — \(Y_i\to r_i\); the box and transport-metric machinery is unchanged.

4 · Correctness anchor & limits

  • \(\hat\mu\equiv 0\ \Rightarrow\) exactly R-OW. With a zero outcome model the residual is \(r=Y\) and the direct term vanishes, so it collapses to R-OW. Verified bit-identical (capped & uncapped, \(\max|\Delta\pi|=|\Delta\mathrm{obj}|=0\)).
  • Box-only sibling. Dropping the Wasserstein term gives R-O-DoublyRobust (= the existing DoublyRobust); R-OW-DoublyRobust adds the per-arm Wasserstein covariate-balance constraint on top.
  • \(\Gamma = 1\ \Rightarrow\) Wasserstein-only AIPW. The box collapses (\(w_i=\hat w_i\) on the box side) and only the transport balance constrains the residual correction.
  • Double robustness. Consistent if either the propensity (via \(\hat w\)) or the outcome model \(\hat\mu\) is correct; the box + Wasserstein additionally guard the propensity side against the unobserved confounder and covariate imbalance.

5 · Capped vs. Uncapped, and arguments

  • Capped adds \(\frac1n\sum_i\pi_k\le\mathrm{cap}_k\); Uncapped drops it.
  • outcome_means (n,K) — the \(\hat\mu\) nuisance; use common.outcome_means(..., cross_fit=True) for an honest cross-fitted estimate.
  • zscore/metric — the Wasserstein ground-cost geometry (z-score the covariates first so no large-unit feature dominates).
  • c_eps/epsilon — scale / override the tight per-arm Wasserstein radius.
  • Gamma · discretize/mesh — MSM box size on the residual correction + discretisation.

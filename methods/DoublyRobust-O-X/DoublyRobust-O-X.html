R-O-DoublyRobust

Robust AIPW (doubly-robust) value maximiser over the O (odds / MSM box ∩ Hájek calibration) uncertainty set. Files: Capped/r_o_doublyrobust_capped.py, Uncapped/r_o_doublyrobust_uncapped.py.

One sentence. R-O-DoublyRobust anchors the policy value on an outcome model \(\hat\mu\) and makes only the leftover IPW correction robust to the unobserved confounder over R-O's box — the doubly-robust analog of R-O. It is the R-O member of the DoublyRobust pair and is bit-identical to the existing box-only DoublyRobust method.

2 · The in-sample problem (robust AIPW value, O set)

Write the factual residual \(r_i = Y_i - \hat\mu_{T_i}(X_i)\). R-O-DoublyRobust maximises the outcome-model value plus the worst-case residual IPW correction over R-O's set:

\[ \boxed{\;\max_{\pi\in\Pi}\ \underbrace{\frac1n\sum_{i}\sum_{k}\pi_k(x_i)\,\hat\mu_k(x_i)}_{\text{direct (outcome model)}}\;+\;\underbrace{\min_{w\in\mathcal U_{\mathrm O}(\Gamma)}\ \frac1n\sum_{i}\pi_{T_i}(x_i)\,w_i\,r_i}_{\text{worst-case residual correction}}\;} \]

with \(\Pi\) the valid-policy set (simplex per cell, tie on each cell, and \(\frac1n\sum_i\pi_k\le\mathrm{cap}_k\) for the capped version), and the O set \(\mathcal U_{\mathrm O}(\Gamma)=\{w: a_i\le w_i\le b_i,\ \sum_{i:T_i=k}w_i=n\}\) — exactly R-O's box + Hájek-calibration set, here acting on the residual \(r\) instead of \(Y\). \(a_i=1+\Gamma^{-1}(\hat w_i-1),\ b_i=1+\Gamma(\hat w_i-1)\).

3 · What is actually solved (dual LP)

Dualising the inner \(\min_w\) gives R-O's box-only dual with \(Y\to r\), plus the (dual-free) direct term added to the objective. Variables \(\pi_k(x_i)\); \(\mu_i,\nu_i\ge 0\); \(\beta_k\) free.

\[ \max_{\pi,\mu,\nu,\beta}\ \ \frac1n\sum_i\sum_k\pi_k(x_i)\hat\mu_k(x_i)\;+\;\sum_i\big(a_i\mu_i-b_i\nu_i\big)\;+\;\sum_k n\beta_k \]
\[ \text{s.t.}\quad \mu_i-\nu_i=\tfrac1n\,r_i\,\pi_{T_i}(x_i)-\beta_{T_i}\ \ \forall i;\qquad \textstyle\sum_k\pi_k(x_i)=1,\ \pi\ \text{tied per cell};\qquad \underbrace{\tfrac1n\textstyle\sum_i\pi_k(x_i)\le\mathrm{cap}_k}_{\textbf{capped only}};\qquad \mu_i,\nu_i\ge0. \]
dual variablemeaning
\(\mu_i,\nu_i\ge0\)box lower/upper duals on \(a_i,b_i\) (acting on the residual correction)
\(\beta_k\) (free)per-arm Hájek-calibration multiplier

4 · Correctness anchor & limits

  • \(\hat\mu\equiv 0\ \Rightarrow\) exactly R-O. With a zero outcome model the residual is \(r=Y\) and the direct term vanishes, so it collapses to R-O. Verified bit-identical (capped & uncapped, \(\max|\Delta\pi|=|\Delta\mathrm{obj}|=0\)).
  • \(=\) DoublyRobust. Same formulation as the existing box-only DoublyRobust method (verified bit-identical) — created as the named O-half of the R-O / R-OW DoublyRobust pair.
  • \(\Gamma = 1\ \Rightarrow\) (non-robust) AIPW. The box collapses (\(w_i=\hat w_i\)) and the objective becomes the ordinary AIPW value of \(\pi\).
  • Double robustness. Consistent if either the propensity (via \(\hat w\)) or the outcome model \(\hat\mu\) is correct; the box additionally guards the propensity side against the unobserved confounder.

5 · Capped vs. Uncapped, and arguments

  • Capped adds \(\frac1n\sum_i\pi_k\le\mathrm{cap}_k\); Uncapped drops it.
  • outcome_means (n,K) — the \(\hat\mu\) nuisance; use common.outcome_means(..., cross_fit=True) for an honest cross-fitted estimate.
  • discretize/mesh — discretise X to the same support as the other methods.
  • Gamma — size of the MSM box on the residual correction.

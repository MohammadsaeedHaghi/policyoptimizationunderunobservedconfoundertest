Three details taken from the authors' code, not the paper text. We ported from CausalML/confounding-robust-policy-improvement (data_scenarios.py), which resolves ambiguities that would otherwise change the experiment: (1) their Γ is on the LOG scale — the code passes Γ = 1.5 into a routine that exponentiates it, so the true odds ratio is Λ* = e1.5 = 4.4817, and that (not 1.5) is the matched Γ we flag; (2) the outcome noise is 2·N(0,1), not N(0,1) as the caption says; (3) the ξ level-shift coefficient is 1.5, not the caption's ω = 1. We verified the realized odds ratio equals Λ* to 10-12 on both branches.
Disclosed reduction: 5-vector to scalar. Their policy class is linear over X ∈ R5; our estimators are univariate, so every method — ours and the baselines alike — sees the SAME scalar index. We run both natural choices and report both: main arm = the nominal-propensity index x = θ'X5/4, and the CATE-index arm x = βtreat'X5/8. The propensity index is the headline because the paper's phenomenon — unconfoundedness-assuming methods DO HARM — survives the reduction there (naive gives back 0.168 of the 0.308 available gain); on the CATE index the naive policy is already within 0.024 of the oracle, so that arm is reported as a DO-NO-HARM check rather than as a win condition. Nothing else about the DGP is touched.

corr(x, S) = -0.366 (main) and -0.708 (CATE index) -- both far from the zero-coupling anchor of the KMZ benchmark, so the Wasserstein term has real signal to use.

Reward = -loss. The oracle treats where CATE > 0: 0.400 of units (main arm).

Doctors treat the treatment-favorable, so the observed contrast sits ABOVE the truth and crosses zero too far right: the naive policy treats 0.667 of units where the oracle treats 0.400, and gives back 0.168 of the 0.308 available between never-treat and oracle.

Declared expectation (written before the wave). This is the X-TRACKABLE corner of our diagnostic map: corr(x, S) = -0.366 on the main arm (versus ≈ 0 on the KMZ'19 benchmark). The prediction is therefore that the Wasserstein term HELPS here — O-W should beat box-only O-X and beat the naive policy it is correcting, and the sharp box should NOT, because sharpness tightens the same one-dimensional bound the box already has without ever using X-structure.
